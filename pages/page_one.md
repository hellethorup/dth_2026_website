## What are the advantages of open source software?

Open source software offers several advantages that go beyond the obvious: cost. One of its main strengths is that it provides users with greater access, transparency, and control over the digital tools they use. Unlike proprietary software, where a company owns and controls the source code, open source software lets anyone access, study, and modify the code (What Is Open Source Software?, 2021).

### Accessibility and affordability

First, open source software makes digital tools more accessible. Since many open source programs are free to use, they can reduce financial barriers for users such as students. For example, Zotero is an open-source reference management tool that helps users collect, organize, and cite academic sources without paying for an expensive subscription. This makes it easier for people with different financial resources to access the same research tools. In this way, open source software can help create more equal opportunities to participate in academic and professional work.

### Transparency and user control

Another important advantage is transparency and user control. Because the source code is publicly available, users can examine how the software works and what it does with their data. They can also modify the software to suit their own needs or continue developing it if the original creators stop maintaining it. This reduces dependence on individual companies and their decisions. In this sense, open source gives users greater ownership and independence over the technology they rely on.

### Collaboration and collective development

Finally, open source encourages collaboration and collective development. Developers and users can contribute to projects by identifying errors, improving features, or translating and documenting the software. Zotero illustrates this through its citation styles. Users have contributed new styles when existing options were missing or when lecturers and institutions required a specific referencing method. This allows the software to develop in response to the practical needs of its users, rather than relying solely on the priorities of its original developers. It also demonstrates how users can take an active role in shaping the tools they depend on.
